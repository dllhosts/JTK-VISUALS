## ⚡ Возможности

- **Система профилей** — создание и переключение между визуальными профилями.
- **Настройка изображения** — яркость, экспозиция, контраст, тени и матовость.
- **Управление цветом** — насыщенность, сочность, оттенок и температура.
- **RGB-каналы** — отдельная настройка красного, зелёного и синего каналов.
- **Визуальные эффекты** — чёрно-белый режим, сепия, дуотон и другие эффекты.
- **LIVE-режим** — применение фильтров в реальном времени.
- **Интенсивность** — регулировка силы применяемых эффектов.

## 🎮 Для чего подходит?

JTK Visuals V2 позволяет настраивать отображение изображения под разные сценарии использования, в том числе для игр, например Rust.
